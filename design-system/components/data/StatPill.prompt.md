**StatPill** — a single metric (streak, crowns, best run): big tabular value, uppercase micro label, coloured accent spine. Lay several in a grid for the "Field Record".

```jsx
<StatPill icon={<LineIcon name="flame" size={15} />} value={42} label="Day streak" accent="var(--accent-today)" big />
```

Set `big` for hero metrics.
