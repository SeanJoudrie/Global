**Badge** — small label chip for region tags, statuses, and the uppercase eyebrow labels that head cards.

```jsx
<Badge accent="var(--accent-codex)">Europe</Badge>
<Badge accent="var(--accent-play)" eyebrow>Today's Game</Badge>
<Badge tone="solid" accent="var(--accent-success)">Complete</Badge>
```

Tones: `soft` (default), `solid`, `outline`. Set `eyebrow` for the tracked uppercase micro-label with the ◦ marker.
